# Quiz App Workspace

В этой папке уже находятся два отдельных репозитория:

- `quiz-app-client` — фронтенд на React + Vite
- `quiz-app-server` — бэкенд на Express + PostgreSQL

Сверху добавлен общий слой оркестрации, чтобы их можно было запускать одной командой через Docker Compose.

## Быстрый старт

1. Скопируйте `.env.example` в `.env`.
2. Задайте безопасный `APP_SECRET`.
3. При необходимости поменяйте `LEADERSHIP_REGISTRATION_CODE` (по умолчанию для локального запуска `lead-123`).
4. Запустите:

```bash
docker compose up --build
```

После старта:

- фронтенд будет доступен на `http://localhost:8080`
- бэкенд будет доступен на `http://localhost:5001`
- Postgres будет доступен на `localhost:5432`

Если у вас уже занят порт `5001`, задайте другой в `.env` через `BACKEND_PORT`.

## Полный Перезапуск С Тестовыми Данными

Чтобы точно применились seed-данные (аккаунты, группы, тесты), нужно пересоздать volume Postgres:

```bash
docker compose down -v
docker compose up --build -d
```

| Что проверить | URL / команда |
| --- | --- |
| Frontend | `http://localhost:8080` |
| Backend health | `http://localhost:5001/health` |
| Вход API | `POST http://localhost:5001/api/auth/login` |
| Публичные группы | `GET http://localhost:5001/api/auth/groups/public` |
| Карточки тестов | `GET http://localhost:5001/api/quizzes/cards` |

## Что делает оркестрация

- поднимает PostgreSQL 16
- инициализирует схему БД из `docker/postgres/init/01-schema.sql`
- собирает и запускает `quiz-app-server`
- собирает и запускает `quiz-app-client`
- сохраняет пользовательские загрузки бэкенда в volume `backend_uploads`

## Структура

- `docker-compose.yml` — общий запуск всех сервисов
- `.env.example` — шаблон переменных окружения
- `docker/postgres/init/01-schema.sql` — инициализация схемы и базовых ролей

## Отдельные репозитории

Фронтенд и бэкенд уже разделены как самостоятельные git-репозитории внутри этой рабочей папки. Общий слой Compose оставлен в корне специально, чтобы можно было разворачивать оба сервиса вместе, не ломая их отдельную историю.
